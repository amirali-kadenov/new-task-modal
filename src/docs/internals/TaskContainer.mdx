# Область задания и калькулятор

Условие и ответ живут в области задания. Если содержимое не влезает по высоте,
окно прячет калькулятор, чтобы освободить место. Снова открыть его можно только
явным нажатием по элементу управления, а не случайным кликом по тексту задачи.

## Обзор

На узком экране или при длинном условии калькулятор и кнопки действий спорят за
высоту. Лучше на время убрать калькулятор, чем обрезать условие.

### Признаки нехватки места

Файл `src/modules/task-modal/model/hooks/layout/get-calc-overflow-handler.ts`:

1. Внутреннее переполнение: у контейнера `clientHeight < scrollHeight`.
2. Не хватает места в окне: высота контейнера больше, чем
   `высота root − шапка − кнопки − высота калькулятора − нижний padding`.

Любое условие → `calc.close()`.

### Клики

Клик по `data-control` (или родителю с ним) — открыть калькулятор. Остальная
область в режиме переполнения калькулятор не открывает.

### Выключение калькулятора

`use-calc-setup.ts`: типы из `TASK_DESCRIPTIONS_WITHOUT_CALC` — калькулятор
выключен целиком.
