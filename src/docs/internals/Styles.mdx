# Стили

Библиотека не просит учебное приложение подключать отдельный файл стилей.
Стили едут внутри JavaScript-бандла и сами попадают в голову документа при
загрузке пакета. Шрифт Halvar подключается отдельной небольшой вставкой, когда
окно задания появляется на странице.

### Инъекция CSS

В `vite.config.ts` включён `vite-plugin-css-injected-by-js`. ADR:
`docs/5-adrs/0002-css-injected-by-js.md`.

### Шрифт

`src/modules/task-modal/model/lib/fonts/inject-fonts.ts` — `injectFonts()`:
создаёт `<style>` с `@font-face`, вешает в `document.head`, не дублирует.
Вызов из `TaskModalController` и из Storybook preview.

### Типичные сбои

- Стили пропали — не собрался / не подхватился `dist/index.js`.
- Кнопка «чужая» — глобальный `button { … }` на хосте.
- Шрифт не тот — не вызвался `injectFonts` или нужен другой вес.
