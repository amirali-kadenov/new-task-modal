# Словарь

Краткие определения терминов раздела Internals. Подробности — на связанных
страницах.

**Ключ задания** — короткий идентификатор из типа задания после отрезания
префикса `Elixir.Task_` (например `4_6_7_1`). По нему ищут экран и запись в
списке разрешённых.
[Шаблоны](?path=/docs/internals-шаблоны--documentation).

**Список разрешённых заданий** — словарь ключей, для которых хост и окно
считают новый интерфейс допустимым.
[Разрешённые задания](?path=/docs/internals-разрешённые-задания--documentation).

**Структурная карта** — таблица «ключ задания → имя реализации экрана»;
перекрывает привязку из файлов глав.
[Шаблоны](?path=/docs/internals-шаблоны--documentation).

**Карта шаблонов** — таблица «имя шаблона → функция загрузки экрана».
[Шаблоны](?path=/docs/internals-шаблоны--documentation).

**Версия ответа** (`lockVersion`) — число для согласованного сохранения ответа
на сервере; при конфликте выставляется признак в состоянии сеанса.
[Проверка ответа](?path=/docs/internals-проверка-ответа--documentation).

**Зависимости хоста** — сервисы и помощники, которые учебное приложение
передаёт в окно (сервер, язык, строки, сокет и др.).
[Контракт с хостом](?path=/docs/internals-контракт-с-хостом--documentation).

**Область задания** — зона с условием и ответом; при нехватке высоты может
скрываться калькулятор.
[Область задания](?path=/docs/internals-область-задания--documentation).

**Ленивая подгрузка** — код пакета и отдельного экрана скачиваются не сразу
при старте урока, а когда они нужны.
[Ленивая загрузка](?path=/docs/internals-ленивая-загрузка--documentation).

**Старый экран внутри нового окна** — хост рисует прежний UI задания в
контейнере новой модалки, если ключа нет в списке разрешённых.
[Старый экран](?path=/docs/internals-старый-экран--documentation).

**Переключатель функций** — необязательный флаг с хоста для поэтапного
поведения (например media в чате).
[Переключатели](?path=/docs/internals-переключатели--documentation).

**Направление письма** — слева направо или справа налево; задаётся помощниками
хоста и применяется к области задания.
[Язык и направление](?path=/docs/internals-язык-и-направление--documentation).

Другие страницы: [Обзор](?path=/docs/internals-обзор--documentation).
