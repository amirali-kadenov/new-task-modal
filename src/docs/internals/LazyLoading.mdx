# Ленивая загрузка

Код нового окна задания и всех экранов шаблонов не лежит целиком в первом
файле скриптов урока. Сначала на страницу попадает только то, без чего нельзя
открыть задачу. Конкретный экран выбранного задания подгружается ещё одним
шагом позже. Так урок открывается быстрее, а неиспользуемые экраны не
скачиваются зря.

Уровень учебного приложения и уровень внутри библиотеки работают независимо:
сначала появляется пакет, затем — конкретный экран. Подробный путь от задания
до экрана: [Шаблоны](?path=/docs/internals-шаблоны--documentation).

### Хост

В `matheducator` контроллер объявляет новую и старую реализации через
отложенный импорт React:

```js
const TaskModalNew = lazy(() => import('@qalan/new-task-modal'))
const TaskModalOld = lazy(() => import('./TaskModalOld'))
```

Список разрешённых заданий:

```js
const module = await import('@qalan/new-task-modal/available-tasks')
```

Файл: `matheducator/reactjs_client/src/modules/pupil/taskModal/TaskModalController.jsx`.

### Библиотека

Карта «ключ → загрузчик экрана»:
`src/modules/tasks/model/component/generate-module-template-map.ts`.

Выбор экрана: `src/modules/tasks/model/component/get-task-component.ts` —
ключ типа, кэш ленивого компонента, иначе `null`.
