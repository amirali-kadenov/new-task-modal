# Список разрешённых заданий

Не каждое задание в уроке сразу открывается новым интерфейсом. Есть отдельный
список ключей: «для этих заданий новый экран уже разрешён». По нему учебное
приложение и само окно решают, показывать новый шаблон или идти в старый путь.
