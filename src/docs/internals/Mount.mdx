# Как окно задания появляется на странице

Библиотека не вставляется в дерево React учебного приложения как обычный
дочерний блок. Контроллер находит на странице заранее подготовленный контейнер,
создаёт внутри него отдельный корень React и рисует окно там. В дереве хоста
функция контроллера возвращает пустое значение — рисовать «снаружи» нечего.

Файл: `src/modules/task-modal/controller.tsx`. ADR 0003.

```ts
export const TaskModalController = (props: TaskModalProps) => {
  setTimeout(() => {
    injectFonts()
    const root = getRoot()
    const closeModal = () => {
      props.closeModal()
      root.unmount()
    }
    root.render(
      <ErrorBoundary>
        <TaskModal {...props} closeModal={closeModal} />
      </ErrorBoundary>,
    )
  }, 0)
  return null
}
```

Экспорт по умолчанию пакета — `TaskModalController` (`src/index.ts`).
При повторном открытии предыдущий корень снимается и удаляется.
