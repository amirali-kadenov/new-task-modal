# Старый экран внутри нового окна

Пока не все задания переведены на новые шаблоны, новое окно умеет показать
старый интерфейс задания внутри своей области контента. Для этого хост
передаёт необязательную функцию отрисовки старого экрана.

Это не то же самое, что открытие **целого** старого окна на стороне учебного
приложения (`?old` и отсутствие в списке) —
[Deployment](?path=/docs/documentation-deployment--documentation).
