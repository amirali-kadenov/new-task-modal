# Как собираются стили модулей

Стили компонентов пишутся рядом с ними в файлах SCSS. Общие функции, миксины и
правила типографики не нужно вручную подключать в каждом файле: сборщик
подставляет их сам.

В `vite.config.ts`:

```ts
css: {
  preprocessorOptions: {
    scss: {
      additionalData: `
        @use "/src/styles/lib/functions" as *;
        @use "/src/styles/lib/mixins" as *;
        @use "/src/styles/design-system/typography" as *;`,
    },
  },
},
```

Локальные классы — `*.module.scss`. Storybook: `@/styles/_index.scss` в
preview. Плагин инъекции CSS — см. страницу Стили.
