# Проверка ответа

После нажатия «Проверить» берётся то, что сейчас в поле ответа, при
необходимости приводятся цифры к обычному виду, на сервер уходит запрос вместе
с заданием и версией для согласованного сохранения. По ответу сервера
обновляются экран и состояние урока.
