### Куда класть код

`src/modules/tasks/ui/templates/<семейство>/` — компонент, `*.module.scss`,
`lib/` (типы, классификация), stories, fixtures (`task.json`, `groups.json`).

### Карты

- `src/modules/tasks/model/template-types.ts` — nested leaf ids.
- `src/modules/tasks/model/template-map.ts` — lazy loaders на leaf UI.
- Главы: `src/modules/tasks/ui/grades/grade-N/chapter-M.ts` (через
  `scripts/generate-grade4-*-chapter-map.ts`).

### Список разрешённых

```bash
# из корня new-task-modal — скрипт generate-available-tasks
# результат попадает в entry available-tasks пакета
```

См. [Разрешённые задания](?path=/docs/internals-разрешённые-задания--documentation).

### Stories

Ориентир по режимам — Documentation/Templates. Для полного сценария —
оболочки тренажёра в `lib/storybook/` семейства.

### Хост

[Deployment](?path=/docs/documentation-deployment--documentation):
`pnpm build:watch`, урок на порту хоста, ключ в списке разрешённых.
