# Математика на экране

В окне задания математика рисуется двумя разными средствами. Одно нужно,
чтобы **показать** формулу в условии или решении. Другое — чтобы человек
**ввёл** формулу в поле ответа. Их нельзя путать: одна и та же запись иногда
пишется по-разному для показа и для ввода.

### Показ

- `src/ui/math-text/math-formula.tsx` — одна формула, inline + `\(...\)`;
- `src/ui/math-text/math-text.tsx` — текст с математикой;
- `normalizeFractionStyle` — дроби.

### Ввод

- `src/ui/math-input/math-input.tsx` — MathQuill, `MATHQUILL_CONFIG`;
- `src/ui/math-symbol-catalog.ts` — `tex` для показа, `mathquill` /
  `getMathQuillTex` для ввода; часть символов помечена как недоступная во вводе.

### Ловушки

- Двойная обёртка `\(\(...\)\)` → ошибка MathJax (`mjx-merror`).
- Разделитель ответов `||` из CMS разбирать до MathJax.
- Кириллица и единицы измерения — проверки в `assert-mathjax-dom.ts`.
