# Statistic

Панель **Statistic** показывает, какие типы и шаблоны заданий есть в живых
данных MathEducator, и насколько новая модалка их закрывает. Локально данные
берутся из snapshot’ов через stats server на порту **3847**. В деплое
Storybook (`pnpm build-storybook:test` / `:prod`) включается
**offline-снимок**: при сборке экспортируется последний локальный snapshot в
`public/stats-static/`, панель читает его без сервера (режим
`VITE_STATS_STATIC`). Это замороженные данные на момент сборки, не live;
вкладка **Генерация** в этом режиме недоступна.

## Зачем это нужно

Statistic отвечает на практические вопросы:

- сколько задач какого типа / группы в выбранной выгрузке;
- какие `templateId` уже в манифесте, в коде `templates` и в маппинге
  `availableTasks`;
- где сигналы покрытия расходятся (манифест ≠ код, маппинг ≠ число задач);
- какие шаблоны ещё нужно реализовать — статический отчёт
  [Пробелы](?path=/docs/statistics-gaps--documentation) (отдельная вкладка
  рядом с Panel; не зависит от рабочего snapshot);
- как быстро открыть конкретную задачу в новом или старом тренажёре.

## Типичный сценарий

1. Запустить stats server (`npm run stats:server` или `start:with-stats`).
2. На **Генерации** выбрать класс (или все) и опционально «С решениями» →
   **Сгенерировать**.
3. Дождаться фаз: очередь → задачи → ответы → анализ → готово.
4. На **Главной** выбрать выгрузку и класс (по умолчанию — последняя с 4
   классом).
5. Смотреть таблицы: сначала **Данные** / **Покрытие**, при необходимости
   раскрыть задачи и открыть в тренажёре.
