# Таблицы статистики

Все таблицы на **Главной** строятся из ответа
`GET /api/snapshots/stats-table?outputDir=&grade=` (live server) либо из
файлов `public/stats-static/stats-table-*.json` в offline-сборке Storybook.
Сервер (или экспорт) отдаёт `groupsTable`, `templatesCoverage`,
`typeDistribution` и `totalTasks`; панель нормализует поля и рисует четыре
подвкладки. Отчёт о missing templates — отдельная вкладка
[Пробелы](?path=/docs/statistics-gaps--documentation) (статический JSON, без
snapshot).

## Покрытие

**Зачем:** понять, закрывает ли новая модалка шаблоны из выгрузки, и где
расходятся три независимых сигнала.

Над таблицей — сводка **манифест %**, **в коде %**, **маппинг %** (доля задач,
у которых соответствующий сигнал «да» / в маппинге).

### Расхождения

Фильтр **«Только расхождения»** оставляет строки, где:

- `implemented` ≠ `inCode`, или
- `availableTasksCount` ≠ `count` (маппинг не покрывает все задачи шаблона в
  выгрузке).

Подсказки в UI (title колонок):

- манифест — список из `implemented-templates.json`;
- в коде — объявления `id:` в `ui/templates`;
- маппинг — whitelist grades + `structural-task-map`.
