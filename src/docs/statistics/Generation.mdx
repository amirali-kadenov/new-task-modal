# Генерация выгрузки

Вкладка **Генерация** запускает job на stats server: тянет задачи (и опционально
решения) из MathEducator API, пишет snapshot на диск и после успеха обновляет
таблицы на **Главной**.

Доступна только локально при живом stats server. В Storybook с
`VITE_STATS_STATIC` (сборки `build-storybook:test` / `:prod`) вкладка скрыта:
там показывается только offline-снимок, собранный при билде.

Тело запроса:

```json
{
  "token": "…",
  "apiBase": "https://preprod.qalan.kz/api",
  "grades": 4,
  "withSolutions": false
}
```

`grades` может быть числом, массивом `[n]` или строкой `"all"`. Без токена
кнопка не стартует job — нужен API token MathEducator (в Storybook — поле над
панелью или `VITE_MATH_EDUCATOR_TOKEN`).

### Статусы (status)

`pending` → `running` → `completed` или `failed`.

Карточка прогресса показывает status · phase, бар `done/total`, при ошибке —
`failedPhase` / `failedRequest` / текст ошибки. Пропущенные уроки и итог
попадают в summary после завершения.

Пока job активен, повторный старт блокируется («Дождитесь завершения…»).

## История сессии

Внизу **Генерации** — список недавних запусков текущей сессии браузера (лимит
хранения выше, в UI показывается укороченный список). Запись помогает
вернуться к `outputDir` / статусу без поиска по диску.

История не заменяет список snapshots на сервере: после перезагрузки страницы
полный перечень берётся снова из `GET /api/snapshots`.

## Запуск сервера

```bash
cd matheducator/reactjs_client
npm run start:with-stats
```

Или отдельно: `npm run stats:server` (порт **3847**) и хост на **8888**.
Health: `GET http://localhost:3847/api/health`.

Если меняли код сервера — перезапустите его, иначе новые выгрузки могут не
появиться в списке.
