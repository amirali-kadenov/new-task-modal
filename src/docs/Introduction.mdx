# Новый тренажёр

Показывает условие задания, принимает ответ, даёт проверить его, открыть
решение, теорию, чат и доску — всё в одном сценарии урока, вместо старой
модалки в MathEducator.

Задачи в продукте разные по форме: текст с полями, формулы, таблицы, тесты,
сравнения и составные экраны. Библиотека раскладывает их по **шаблонам** —
повторяемым раскладкам UI. Одно и то же оформление экрана обслуживает много
разных текстов и чисел; новый шаблон нужен, когда меняется сама структура
(число полей, сетка, тип выбора), а не только формулировка.

Миграция идёт постепенно. Хост решает для каждого задания: открыть новый UI
или оставить старый — по белому списку и настройкам урока. Так можно
сравнивать оба варианта на одних данных и подключать шаблоны по мере готовности,
не переключая сразу весь продукт.

Эта документация и Storybook вокруг неё — стенд библиотеки
`@qalan/new-task-modal`: здесь смотрят варианты заданий и компоненты,
согласовывают состояния и проверяют поведение тренажёра **без** полного
развёртывания хоста. Ниже — карта разделов и как читать остальные страницы.

### Что отдаёт эта библиотека наружу

Пакет называется `@qalan/new-task-modal`. Снаружи хост обычно импортирует один
главный вход — контроллер модалки (`TaskModalController` из `src/index.ts`).
Вместе с ним доступен тип пропсов, чтобы приложение знало, какие данные и
колбэки нужно передать.

Цепочка простая. Учебное приложение (урок, белый список заданий, контейнер на
странице) вызывает контроллер. Контроллер поднимает модалку: каркас (шапка,
условие, ответ, кнопки) и подставляет нужный шаблон задания. Внешний вид кнопок,
полей и отступов берётся из общей дизайн-системы.

Хосту нужно передать задачу, зависимости (сеть, переводы, тосты и т.д.),
состояние сеанса, действия вроде «проверить ответ» / «дальше» и способ закрыть
модалку. Подробный разбор полей — на странице
[Архитектура](?path=/docs/documentation-architecture--documentation).

### Где что лежит в коде

Модалка как продукт живёт в `src/modules/task-modal`: контроллер, хранилище,
каркас экрана, шрифты. Логика заданий и шаблонов — в `src/modules/tasks`
(карта типов, классификация, главы классов, папка `templates`). Рядом в
Storybook есть тренажёр, чат и доска — это окружение вокруг модалки, а не сама
библиотека для хоста. Общие кнопки, инпуты и токены стилей — в `src/ui` и
`src/styles`.

### Как подключить к учебному приложению

Хост смотрит на собранную папку `dist/` этого репозитория (не на исходники
напрямую). Поэтому после правок нужна сборка — удобно держать `pnpm build:watch`
в одном терминале и `npm start` хоста в другом. Модалка монтируется в элемент
`#task-modal-wrapper` на странице урока.

```bash
# new-task-modal
pnpm build:watch

# matheducator/reactjs_client
npm start
```

### На что обратить внимание

Если на странице нет контейнера `#task-modal-wrapper`, модалке некуда
показаться. Параметр `?old` в адресе принудительно включает старую модалку —
удобно сравнивать. Задача, которой нет в белом списке `availableTasks`, уйдёт в
старый UI, даже если шаблон уже написан в этой библиотеке. Если правили `src`,
но на порту 8888 ничего не изменилось — скорее всего не обновился `dist/` или
страницу хоста не перезагрузили.

Подробнее: [Deployment](?path=/docs/documentation-deployment--documentation).
