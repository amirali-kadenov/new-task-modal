# `formula.multi.stack.n2.before`

Два `MathInput` столбиком с before-подписями (частное / остаток), формула
деления сверху (например `91 : 10 = `).

## Когда выбирать

`answerInput.input1` / `input2`, `inline: false`, непустой `before`.

## UI

- `TaskTitle` + `TaskDescription` (формула деления)
- stack: `before` + input на каждой строке
