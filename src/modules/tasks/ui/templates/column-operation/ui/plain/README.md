# `columnOperation.plain`

Один `MathInput` под формулой в столбик (`\begin{array}…`).

## Когда выбирать

`answerInput.type: 10`, пустые `before` / `after`. Покрывает structural groups
`columnOperation_1` (content string) и `columnOperation_2` (content Translation).

## UI

- `TaskTitle`
- `TaskDescription` (формула)
- один `MathInput`
