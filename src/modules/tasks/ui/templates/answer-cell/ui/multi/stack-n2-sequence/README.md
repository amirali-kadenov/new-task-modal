# `answerCell.multi.stack.n2.sequence`

Числовая последовательность с двумя пропусками (`answercell` между литеральными числами, напр. `28; 33; answercell; answercell; 48; 53; 58; 63; 68`) — в отличие от `answerCell.multi.stack.n2.plain` (арифметика, `___ + ___`), инпуты здесь фиксированной узкой ширины, не растягиваются.
