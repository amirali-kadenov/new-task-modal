# 💬 API Reference: Chat Component

Изолированный двухвкладочный модуль чата (AI Помощник + Живые Менторы).

---

## 🚀 Экспорт и Использование

Чат может экспортироваться как отдельный React-компонент вне модалки задания:

```tsx
import { Chat } from '@qalan/new-task-modal'

<Chat
  props={taskModalProps}
  onClose={() => setOpen(false)}
/>
```

---

## 🎛️ Вкладки чата

1. **AI-Чат**:
   - **Доступность**: 24/7.
   - **Протокол**: WebSocket (`deps.socketController`).
   - **Функционал**: Отправка подсказок по текущему заданию, пояснение шагов решения, генерация наводящих вопросов без прямой выдачи ответа.

2. **Ментор**:
   - **Доступность**: С 10:00 до 23:00.
   - **Протокол**: REST API (`deps.api`) + WebSocket-уведомления.
   - **Функционал**: Прямая связь с дежурным преподавателем/ментором платформы.

---

## ⚙️ ChatProps

| Проп | Тип | Описание |
| :--- | :--- | :--- |
| `props` | `TaskModalProps` | Основные пропсы и зависимости модалки. |
| `onClose` | `() => void` | Коллбэк закрытия окна чата. |
| `isEmbedded` | `boolean?` | Рендерится ли чат встроенным в панель или всплывающим окном. |
