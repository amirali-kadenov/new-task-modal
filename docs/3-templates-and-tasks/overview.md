# 🧩 Обзор шаблонов заданий (Task Templates Overview)

В `@qalan/new-task-modal` каждое задание рендерится через соответствующий **шаблон** (Template). Все шаблоны расположены в директории `src/modules/tasks/ui/templates/`.

---

## 📚 Каталог шаблонов

| Тип | Директория | Описание |
| :--- | :--- | :--- |
| `text` | `text/` | Текстовое условие со встроенными полями ввода (inline/block). |
| `answerCell` | `answer-cell/` | Задания с сеточкой ячеек ответа (до 6 разрядов/ячеек). |
| `formula` | `formula/` | Формульные задания с переменными и математическими полями. |
| `columnOperation` | `column-operation/` | Столбиковые операции (сложение, вычитание, умножение, деление в столбик). |
| `table` | `table/` | Табличные задания с ячейками различных типов (заполняемые, статичные, выпадающие списки). |
| `test` | `test/` | Классические тесты с одиночным или множественным выбором. |
| `comparison` | `comparison/` | Сравнение величин и выражений (знаки `<`, `>`, `=`). |
| `equation` | `equation/` | Пошаговое решение уравнений. |
| `multiInput` | `multi-input/` | Комплексные задания с несколькими независимыми секциями ввода. |

---

## 📐 Анатомия компонента шаблона

Каждый шаблон следует единому паттерну реализации:

```text
src/modules/tasks/ui/templates/<template-name>/
├── ui/                     # Подкомпоненты рендеринга
│   ├── plain/              # Одиночное задание
│   ├── multi/              # Групповые/составные задания
│   └── <variant>.tsx       # Специфичные вариации верстки
├── model/                  # Форматирование и парсинг ответа
├── <template-name>.tsx     # Корневой компонент шаблона
├── README.md               # Документация шаблона
└── <template-name>.stories.tsx # Storybook истории
```

---

## ⚙️ Модификаторы верстки

Многие шаблоны поддерживают флаги отображения:
- `inline: true` — поля ввода интегрируются прямо в текст условия.
- `stack: true` — элементы подзадач располагаются друг под другом.
- `beforeAfter` — отображение вспомогательных графических элементов или пояснений до/после текстового блока.
