# 🔰 Чек-лист разработчика (Onboarding Cheatsheet)

Главная шпаргалка для погружения в проект и работы с кодовой базой `new-task-modal`.

---

## 🗺️ Картография репозитория

| Путь | Назначение |
| :--- | :--- |
| `src/modules/task-modal/` | Контроллер, провайдеры контекста и монтирование модалки |
| `src/modules/tasks/` | Ядро заданий: шаблоны, маппинги по классам/главам, состояние |
| `src/modules/chat/` | Двухвкладочный чат (AI + Ментор) |
| `src/modules/canvas/` | Графический канвас для решений учеников |
| `src/modules/audio/` | Аудиоплеер для озвучки вопросов |
| `src/styles/` | SCSS переменные, миксины, глобальная дизайн-система |

---

## 🔑 Правила и соглашения

1. **Изоляция стилей**:
   - Используйте CSS Modules (`*.module.scss`).
   - Стили инжектируются в JS через `vite-plugin-css-injected-by-js`. Не вносите глобальные CSS-классы без префикса.

2. **Поиск кода**:
   - Используйте `semble search "<запрос>" ./new-task-modal` для поиска логики или символов.

3. **Зависимости с хостом**:
   - Любые внешние взаимодействия (API, события, тосты, локализация) передаются через параметр `deps` в `TaskModalController`.
   - Не импортируйте модули `matheducator` напрямую через относительные пути!

4. **Индикация доступных заданий**:
   - После добавления нового шаблона или маппинга запустите `pnpm generate-available-tasks`.
