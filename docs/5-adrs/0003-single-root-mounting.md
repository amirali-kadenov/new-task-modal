# ADR 0003: Монтирование через отдельный React Root (`createRoot`)

- **Статус**: Принято (Accepted)
- **Дата**: 2026-07-30

---

## 🎯 Контекст и Проблема

Хост-приложение (`matheducator`) построено на комбинации Elixir Phoenix шаблонов и старого React 16.x / legacy Webpack. Импорт компонентов React 19 прямо в дерево React 16 хоста приводит к несовместимости версий React и хуков.

---

## 🚀 Принятое решение

Использовать паттерн **Isolated React Root**. `TaskModalController` монтирует отдельный самостоятельный React 19 Root в специальный контейнер `#task-modal-wrapper` с помощью `ReactDOM.createRoot`.

---

## ⚖️ Последствия

### Плюсы:
- Полная изоляция версий: `new-task-modal` может использовать React 19 и React Compiler независимо от версии React хоста.
- Устойчивость к сбоям: ошибки в модальном окне не обрушивают основное дерево хост-приложения.

### Минусы:
- Отсутствие прямого проброса React Context из хоста (все зависимости должны передаваться явно через `deps`).
