# ADR 0002: Инжекция стилей через JS (vite-plugin-css-injected-by-js)

- **Статус**: Принято (Accepted)
- **Дата**: 2026-07-30

---

## 🎯 Контекст и Проблема

При подключении внешнего UI-модуля к legacy-приложению (в данном случае `matheducator`) возникает проблема каскадирования стилей:
1. Подключение отдельного CSS-файла библиотеки в HTML хоста может перекрываться глобальными правилами хоста.
2. Необходимость вручную импортировать `import '@qalan/new-task-modal/dist/index.css'` в хост-коде усложняет DX.

---

## 🚀 Принятое решение

Использовать плагин `vite-plugin-css-injected-by-js` при сборке бандла `new-task-modal`. Все SCSS/CSS стили компилируются в JS-строки и автоматически инжектируются в тег `<head>` при импорте модуля `dist/index.js`.

---

## ⚖️ Последствия

### Плюсы:
- Нулевая конфигурация для хоста: достаточно импортировать `TaskModalController`, стили подтягиваются автоматически.
- Гарантия наличия необходимых шрифтов и стилей UI-компонентов.

### Минусы:
- Небольшое увеличение размера JS-бандла.
